## Angle

WorkBuddy support makes the broader configuration problem concrete: project/user/connector Skills, long-term context files, MCP configuration, duplicate or overlapping triggers, and context cost can be inspected locally in one workflow.

## Recommended post

```text
AI Agent 的配置层也会变成一棵依赖树：项目 Skill、用户 Skill、连接器 Skill、Memory 和 MCP 叠在一起，Agent 的行为就可能开始漂移。

我发布了 skill-doctor v0.5.0，新增腾讯 WorkBuddy 一等支持。它可以在本地盘点 WorkBuddy 的 Skill、长期上下文和静态 MCP 配置，并检查重复、触发冲突、安全风险和上下文成本。

先试一个只读命令：

npx @evilstar2025/skill-doctor@0.5.0 scan --platform workbuddy
npx @evilstar2025/skill-doctor@0.5.0 cost --platform workbuddy

默认不上传 Skill 文件；动态 MCP/运行时状态也不会被无证据地当成已启用资源。

Release: https://github.com/evilstar2016/skill-doctor/releases/tag/v0.5.0
反馈：缺失的平台路径、误报，或脱敏后的真实配置差异，欢迎提交到 https://github.com/evilstar2016/skill-doctor/issues/4
```
