## Angle

Open-source trust plus a runnable local proof: `skill-doctor` now has an MIT license, contributor guidance, a security policy, and a local UI for inspecting agent skills and instructions.

## Recommended post

```text
AI coding-agent setups are turning into a second dependency tree: skills, rules, instructions, MCP config, and project memory spread across tools.

I maintain skill-doctor, a local CLI/UI that helps inspect that layer for duplicate skills, overlapping triggers, risky instructions, context cost, and cross-agent drift.

The current v0.4.1 release is open-source under MIT and includes contributor and security guidance. You can try it without uploading your skill files:

npx @evilstar2025/skill-doctor scan
npx @evilstar2025/skill-doctor ui

If you prefer a redacted fixture first:

git clone https://github.com/evilstar2016/skill-doctor.git
cd skill-doctor/examples/conflicted-agent-project
npx @evilstar2025/skill-doctor audit --scope project

Repo: https://github.com/evilstar2016/skill-doctor
Release: https://github.com/evilstar2016/skill-doctor/releases/tag/v0.4.1

The most useful feedback is one missing agent path, one false positive, or one redacted case where overlapping instructions changed an agent's behavior:
https://github.com/evilstar2016/skill-doctor/issues/4
```
