# 技能库回收与部署研发计划

状态：已完成（2026-07-25）

## 交付标准

- 待纳管技能可单个或批量纳管；成功后中心库有记录，原 Agent 目录变为指向中心库的目录链接。
- 同名不同内容的冲突不会被静默覆盖，必须有明确、可执行的处理方式。
- 所有技能库内的确认、详情、设置和部署交互都使用居中应用内弹窗，不依赖浏览器原生 `confirm`。
- 每项已纳管技能都有可见的“部署到 Agent”入口，可明确选择目标 Agent、全局/项目范围、复制/链接和冲突策略。
- 移除重复或无效入口；功能由自动化测试、构建和一次本地实际回收验证共同证明。
