# 上下文成本分析 模块测试用例

## 1. 基本信息
- 测试对象：skill-doctor「上下文成本分析」功能模块
- 模块编号前缀：**CC**（Context Cost）
- 用例类型：功能测试 / 边界测试 / 异常测试 / 配置测试
- 适用场景：Token 估算（estimateContextCost/tokenCounter）、MCP 成本分析（scanMcpServers/listMcpTools）、Codex 上下文扫描（scanCodexContext/codexContextConfig/scanCodexPluginCache）、Codex 资源控制（codexControls）、cost/context CLI 命令
- 对应测试观点：见 `02-上下文成本分析-测试观点.md`（编号 CC-TP-xx）

## 2. 自动化说明

- 本模块 34 条用例**全部**已落地为 Vitest 自动化脚本，其中 4 条依赖真实本地网络/子进程（MCP 工具发现的 stdio/HTTP/SSE 协议），属于"重量级但仍是脚本"的自动化，不涉及人工操作。
- 每条用例标注：
  - **自动化状态**：`✅ 已自动化（已有）` = 仓库中已存在对应脚本；`✅ 已自动化（本轮新增）` = 本轮为覆盖缺口新写的脚本。
  - **测试脚本**：脚本文件路径 + `describe`/`it` 标题。
- 运行方式：见文档末尾的"输入 → 环境 → 输出 速查表"（与观点文档中的表一致，此处不重复）。
