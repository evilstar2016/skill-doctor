# Skill Doctor 前端设计规范

本项目固定采用用户提供的 Sentry 风格：深紫开发者工作台。所有页面共用一套主题，不提供浅色、系统主题或青绿／蓝青切换。旧的浏览器主题偏好不参与渲染。

## 唯一主题入口

`src/theme.css` 是颜色、字体、间距、圆角和阴影变量的唯一来源，由 `src/styles.css` 引入。页面 CSS 和组件消费变量，不再定义另一套根主题，不加入硬编码品牌色或根据系统偏好覆盖配色。

| 用途 | 变量／规则 |
| --- | --- |
| 页面、侧栏 | `--bg: #1f1633`、`--bg-deep: #150f23`，不使用纯黑背景 |
| 卡片层级 | `--surface`、`--surface-2`、`--surface-3`，均为暖紫 |
| 分隔线 | `--border: #362d59`；控件边界用 `--border-strong` |
| 主按钮 | `--button-bg: #79628c`、白字、13px 圆角、`--shadow-inset`；悬停保留内阴影并增加外阴影 |
| 导航选中 | `--selected: #422082`，白字和紫色边缘指示 |
| 交互紫 | `--interactive: #6a5fc1`；小号链接和数据使用更亮的 `--accent`／`--accent-text` 保持深色背景上的可读性 |
| 青柠强调 | `--highlight: #c2ef4e`，每区最多一处，不铺满按钮、状态或图表 |
| 风险语义 | danger 为粉色，warning 为珊瑚，success 为柔和绿，info 为淡紫；同时展示文字或图标 |
| 焦点 | 粉色外框和 `--ring`，不可仅靠背景变化表达键盘焦点 |
| 代码 | Monaco → Menlo → Ubuntu Mono → monospace；代码块使用深紫背景 |

## 字体和排版

- UI 使用 Rubik 优先字体栈，缺少字体时使用本机系统字体；中文使用 PingFang SC／Microsoft YaHei。运行时不请求外部字体服务。
- 未附带 Dammit Sans 字体资产，因此不宣称该字体已安装，也不添加网络依赖。工具页面不使用营销首页的 88px 大标题。
- 页面标题约 30px／700，区块标题 20–24px／600，正文 13–16px／400，导航 14px／500，标签 11–12px／600。
- 按钮和技术标签采用大写与至少 0.2px 字距；正文、文件名和路径保留原始大小写。
- 常规间距使用 8px 节奏，细节允许 4px；控件圆角至少 6px，面板 10–12px。
- 玻璃效果限于粘性顶栏等覆盖层：`blur(18px) saturate(180%)`。表格保持实色，保证密集信息清晰。

## 布局与验收

保留工作台的信息密度、原有导航和业务交互，不套用营销页布局。桌面保留侧栏，窄屏沿用折叠导航和单列内容；长表格使用局部滚动，不让整页溢出。

改动后检查概览、问题、上下文优化、资源、历史、技能库及设置弹窗。至少验证桌面和手机宽度、键盘焦点、禁用状态、长路径及空状态，并运行仓库要求的测试、UI 类型检查、构建和 `git diff --check`。
